# Orbit Tide

React Native / Expo ile hazırlanmış gerçek zamanlı 3B yörünge oyunu.

- Kaynak proje: `orbit-tide.zip`
- Sürüm: 1.2.0
- Android paket adı: `com.ulasugurlu.orbittide`
- APK hedefi: ARM64 (`arm64-v8a`), release

## APK derlemesi

GitHub Actions içindeki **Build Orbit Tide APK** iş akışı projeyi kurar, oyun testlerini çalıştırır, Android projesini üretir ve oyun kodunu APK içine gömer.

Başarılı çalışmanın **orbit-tide-apk** çıktısında `Orbit-Tide-1.2.0.apk`, dosya özeti ve derleme bilgisi bulunur. Bu APK Android'e doğrudan kurulum için hazırlanır. Telefon üzerinde Expo Go veya Metro sunucusu gerekmez.

Kaynak arşivinin içindeki README, QA raporu ve araştırma notu ayrıntıları içerir.
